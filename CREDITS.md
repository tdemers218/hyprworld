# Credits and provenance

## Hyprscroll2D upstream

Hyprworld is derived from [Hyprscroll2D](https://github.com/kirollosatef/hyprscroll2d),
created by **Kirollos Atef (kirollosatef)** and its contributors. The original
project supplied the two-dimensional Lua layout foundation, core navigation,
Omarchy integration and packaging, installation scripts, tests, and initial
documentation. Its copyright and MIT permission notice remain in [LICENSE](LICENSE).
The Git history retains the upstream commits.

## Hyprworld fork

**[Tristan Demers (tdemers218)](https://github.com/tdemers218)** maintains this independent fork. Fork development expands
visible window groups, pointer gestures, overview/minimap, zoom, themed settings,
shortcut validation, mouse focus, delayed compaction, shared workspace
navigation, placement paths and startup templates. See [CHANGELOG.md](CHANGELOG.md) for the release boundary.

Hyprworld is not an official release or endorsed successor of Hyprscroll2D,
Hyprland, or Omarchy.

## Platform and historical references

Thanks to the Hyprland, Omarchy, and Quickshell projects for the platform this
plugin builds on. [Historical research notes](docs/RESEARCH.md) preserve the
upstream investigation and related-project references; those references do not
imply code was copied from every listed project.
